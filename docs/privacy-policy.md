# DustNote 隐私政策

> 最后更新：2026-06-27
> 适用版本：DustNote v1.0.0 及以上

## 1. 我们是谁

DustNote（"我们"）是一款个人笔记应用。本政策说明我们在你使用 DustNote 时如何收集、使用和保护你的信息。

## 2. 核心原则

1. **不收集不必要的数据**——只收集服务运行所必需的最少信息
2. **服务端不存明文**——采用端到端加密，你的笔记在传输到服务端前已在设备加密
3. **不卖数据**——任何情况下都不会向第三方出售你的数据
4. **无第三方追踪**——不集成 Google Analytics、Sentry 等任何第三方分析或追踪服务

## 3. 我们收集的数据

### 3.1 你主动提供的数据

| 数据                  | 用途       | 存储位置         |
| --------------------- | ---------- | ---------------- |
| 主密码（哈希后）      | 身份验证   | 服务端，仅哈希值 |
| 12 位恢复码（哈希后） | 密码找回   | 服务端，仅哈希值 |
| 笔记密文              | 同步与备份 | 服务端           |
| 附件密文              | 同步与备份 | 服务端           |
| 主题与偏好            | 个性化     | 服务端 + 本地    |

### 3.2 自动收集的数据

| 数据                                     | 用途             | 保留时间           |
| ---------------------------------------- | ---------------- | ------------------ |
| 设备指纹（UA + 屏幕 SHA-256 前 12 字符） | 设备管理         | 永久（可手动踢出） |
| IP 地址（仅哈希，加盐 24h 轮换）         | 反滥用、安全审计 | 7 天               |
| 访问时间戳                               | 同步与审计       | 永久（仅元数据）   |
| 错误日志（已脱敏）                       | 故障排查         | 90 天              |

## 4. 端到端加密（E2EE）

你的笔记内容、标题、标签、附件原始文件名在**离开你的设备前**已使用 AES-256-GCM 加密。解密密钥由你的主密码派生，**服务端不保存也无法解密**。

这意味着：

- 我们**无法**读取你的笔记内容
- 如果你忘记主密码且丢失恢复码，**我们无法帮你恢复**——这是设计而非缺陷
- 一旦发生服务端数据泄露，攻击者得到的只是密文

## 5. 你的权利

| 权利     | 操作                                      |
| -------- | ----------------------------------------- |
| 导出     | 设置 → 数据 → 全量导出加密 ZIP            |
| 删除账户 | 设置 → 数据 → 删除账户（30 天后物理删除） |
| 查看数据 | 设置 → 数据 → 我的数据清单                |
| 拒绝追踪 | 默认无追踪，无需操作                      |
| 切换设备 | 设置 → 设备管理 → 踢出旧设备              |

## 6. 第三方服务

我们不集成任何第三方分析、广告、追踪、社交服务。客户端不向 Google Fonts 等任何第三方域名发请求（字体自托管）。

## 7. 数据存储与跨境

- 默认存储区域：可配置（见自托管指南）
- 跨境传输：仅在你主动选择海外节点时发生；默认区域在中国大陆

## 8. 未成年人

DustNote 不向 14 岁以下未成年人提供服务。如发现误注册，请联系 [privacy@dustnote.app](mailto:privacy@dustnote.app) 删除。

## 9. 政策变更

重大变更将通过应用内通知与邮件提前 **30 天**告知。变更生效后继续使用即视为接受。

## 10. 联系方式

- 邮箱：[privacy@dustnote.app](mailto:privacy@dustnote.app)
- 邮件回复时间：7 个工作日内

## 11. 适用法律

本政策适用中华人民共和国《个人信息保护法》与欧盟 GDPR（如适用）。
