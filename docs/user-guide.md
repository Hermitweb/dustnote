# DustNote 用户使用手册

> 适用版本：v2.0.0 及以上

## 1. 5 分钟上手

### 1.1 选择使用模式（v2.0.0 新增）

首次打开 DustNote，会进入模式选择页面：

| 模式              | 适用场景                   | 是否需要服务器             |
| ----------------- | -------------------------- | -------------------------- |
| 🏠 **单机使用**   | 隐私敏感、单设备使用、试用 | 不需要                     |
| 🌐 **连接服务器** | 多设备同步、在线分享       | 需要（自部署或公共服务器） |

**单机模式特点**：

- 数据仅存在本设备
- 无需服务器，开箱即用
- 不支持跨设备同步与在线分享
- 适合隐私敏感或试用场景

**联机模式特点**：

- 数据同步到服务器
- 跨设备同步、在线分享
- 需部署或连接 DustNote 服务器
- 适合多设备使用

> 💡 未来可一键迁移到另一种模式，不丢数据。详见 [§7 模式切换](#7-模式切换v200-新增)。

### 1.2 创建主密码

1. 选择模式后进入"创建主密码"页面
2. 输入一个**至少 10 位**的主密码（建议 16 位以上）
3. 再次输入以确认
4. 系统生成 12 位**恢复码**，请**立即抄写**在安全的地方
5. 完成后进入主页

> ⚠️ **主密码不可找回**。如果忘记，只有恢复码能帮你重置。请妥善保管。
>
> v2.0.0 单机模式：recover 后 masterKey 保留，**笔记密文无需重加密**，历史笔记继续可用。

### 1.3 创建第一篇笔记

1. 主页右上角点击 **+** 按钮
2. 输入标题
3. 在编辑器中输入内容（支持 Markdown）
4. 自动保存（每 1.5 秒）
5. 点击 ← 返回即可

### 1.4 切换设备

**联机模式**：

1. 在新设备上打开 DustNote
2. 选择「连接服务器」→ 输入服务器地址
3. 点击"已有账户？登录"
4. 输入**同一主密码**
5. 笔记自动同步

**单机模式**：

- 不支持跨设备同步
- 可通过导出 ZIP → 在新设备导入的方式转移数据（详见 [§5 导入与导出](#5-导入与导出)）
- 或迁移到联机模式后再多设备使用

## 3. 主题与个性化

### 3.1 切换主题

设置 → 主题 → 6 套主题任选：
- 薄荷晨光（默认）
- 雾霭蓝调
- 暮色森林
- 焦糖暖光
- 樱粉物语
- 极简白

### 3.2 切换明暗

外观模式：
- 跟随系统
- 始终亮色
- 始终暗色

### 3.3 字体与密度

- **字体**：系统默认 / 思源黑体 / 霞鹜文楷
- **密度**：舒适 / 标准 / 紧凑

## 4. 导入与导出

### 4.1 导入

支持 `.txt` / `.md` / `.docx`

设置 → 导入导出 → 选择文件 → 预览 → 确认

冲突时可选：**合并 / 覆盖 / 跳过**

### 4.2 导出

支持 **Markdown / HTML / PDF / JSON**

设置 → 导入导出 → 选择格式 → 筛选范围 → 下载 ZIP

**全量备份**推荐使用 JSON 格式。

## 5. 分享

### 5.1 创建分享

1. 打开笔记
2. 点击右上角 ⋯ → 分享
3. 可选：
   - 访问密码（4-32 位）
   - 有效期（1 天 / 7 天 / 30 天 / 永久）
   - 备注（仅自己可见）
4. 复制链接或扫码分享

### 5.2 管理分享

设置 → 分享管理

可查看：
- 链接状态
- 查看次数
- 过期时间

可操作：
- 复制链接
- 调整过期
- 吊销（立即失效）

## 6. 设备管理

设置 → 设备管理

可查看所有已登录设备，点击 **踢出** 立即清除该设备的会话。

## 7. 自动锁屏

默认空闲 **15 分钟**自动锁屏。可在设置中调整为 5/15/30/60 分钟或"永不"（不推荐）。

移动端切到后台时**立即**锁屏。

## 8. 数据管理

### 8.1 导出全部

设置 → 数据 → 全量导出 → 收到加密 ZIP

ZIP 含 `notes.json`、`tags.json`、`preferences.json`、`attachments/`。

ZIP 使用**导出密码**加密（与主密码不同），请妥善保管。

### 8.2 删除账户

设置 → 数据 → 删除账户

⚠️ 30 天后物理删除，期间可登录恢复。

## 9. 常见操作

### 9.1 找回主密码

1. 解锁页 → "忘记密码"
2. 输入 12 位恢复码
3. 设置新主密码

### 9.2 跨设备转移

方法 A：登录同一账户自动同步
方法 B：导出 → 在新设备导入

### 9.3 离线使用

- Web：依赖浏览器 IndexedDB，断网仍可读已缓存笔记
- 桌面：本地 SQLite，完全离线可用
- Android：本地 SQLite，完全离线可用
- 小程序：依赖网络

> v2.0.0 单机模式：所有端默认离线工作，无需网络。

## 10. 故障排除

| 现象 | 排查 |
|------|------|
| 忘记主密码 | 用恢复码重置 |
| 同步卡顿 | 检查网络 / 重启应用 / 设置 → 数据 → 强制同步 |
| 主题未生效 | 重启应用 |
| 笔记丢失 | 检查回收站 / 设置 → 数据 → 查看最近活动 |
| 编辑器卡顿 | 拆分超大笔记（> 50k 字） |
| 单机模式数据丢失 | 设备丢失则不可恢复；若有备份 ZIP 可在新设备导入 |
| 单机模式锁定 | 6 次密码错误锁 15 分钟，等待后重试或用恢复码重置 |

## 12. 模式切换（v2.0.0 新增）

支持 standalone ↔ online 一键迁移，数据不丢失。**显式触发**：在设置中点击「迁移数据」按钮，弹窗确认后执行。

### 12.1 单机 → 联机

1. 设置 → 模式切换 → 迁移到联机模式
2. 输入服务器地址 + 主密码
3. 系统检查服务器状态（必须未 setup）
4. 自动上传所有本地数据到服务器
5. 上传成功后清空本地业务数据（保留鉴权信息备查）
6. 切换到联机模式，重启 App

### 12.2 联机 → 单机

1. 设置 → 模式切换 → 迁移到单机模式
2. 输入新主密码 + 恢复码
3. 系统从服务器拉取全量密文
4. 写入本地存储
5. 切换到单机模式，重启 App

### 12.3 迁移失败怎么办

- **原子化迁移**：任一步骤失败自动回滚，**不会丢失数据**
- 失败后仍处于原模式，可重试
- 弹窗显示失败原因 + 重试按钮

详见 [standalone-mode.md §7](../.trae/documents/standalone-mode.md)。

## 13. 单机模式专属指南（v2.0.0 新增）

### 13.1 数据存储位置

| 端 | 存储位置 | 容量 |
|----|---------|------|
| Web / Desktop | IndexedDB | GB 级 |
| Mobile (Android/iOS) | AsyncStorage | 设备存储 |
| 微信小程序 | Taro.setStorage | 单 key 10MB |

### 13.2 备份建议

> 单机模式数据仅存在本设备，**设备丢失则数据丢失**。强烈建议定期导出 ZIP 备份。

| 备份频率 | 适用场景 |
|----------|---------|
| 每周一次 | 日常使用 |
| 每次大量编辑后 | 重要数据 |
| 卸载 App 前 | 必备 |
| 切换设备前 | 必备 |

**备份流程**：

1. 设置 → 数据 → 导出备份
2. 选择导出密码（**与主密码不同**）
3. 保存 ZIP 到安全位置（云盘 / U 盘 / 加密邮件）

### 13.3 客户端锁定

| 触发 | 行为 |
|------|------|
| 连续 6 次密码错误 | 锁定 15 分钟 |
| 锁定期间 | 无法尝试解锁 |
| 成功解锁 | 失败计数清零 |

锁定计数器持久化，重启 App 不重置。

### 13.4 恢复码重置流程

1. 解锁页 → "忘记密码"
2. 输入 12 位恢复码
3. 设置新主密码
4. 系统生成**新恢复码**（旧恢复码失效）
5. 单次显示新恢复码，**强制抄写**

> v2.0.0 关键设计：recover 后 masterKey 保留，**历史笔记密文无需重加密**，所有笔记继续可用。

### 13.5 单机模式限制

| 功能 | 是否支持 |
|------|---------|
| 笔记/文件夹/标签 CRUD | ✅ |
| 主题/字体/密度 | ✅ |
| 导入/导出 | ✅ |
| 文件分享（txt/md/html/pdf） | ✅ |
| 跨设备同步 | ❌ |
| 在线分享链接 | ❌ |
| 设备管理 | ❌（UI 隐藏） |
| 服务端备份 | ❌（仅本地导出 ZIP） |

> 小程序单机模式受 10MB 限制，仅推荐轻量试用。数据量大请迁移到联机模式。
