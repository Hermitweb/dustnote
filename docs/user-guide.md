# DustNote 用户使用手册

> 适用版本：v1.0.0 及以上

## 1. 5 分钟上手

### 1.1 创建主密码

1. 首次打开应用，进入"创建主密码"页面
2. 输入一个**至少 10 位**的主密码（建议 16 位以上）
3. 再次输入以确认
4. 系统生成 12 位**恢复码**，请**立即抄写**在安全的地方
5. 完成后进入主页

> ⚠️ **主密码不可找回**。如果忘记，只有恢复码能帮你重置。请妥善保管。

### 1.2 创建第一篇笔记

1. 主页右上角点击 **+** 按钮
2. 输入标题
3. 在编辑器中输入内容（支持 Markdown）
4. 自动保存（每 1.5 秒）
5. 点击 ← 返回即可

### 1.3 切换设备

1. 在新设备上打开 DustNote
2. 点击"已有账户？登录"
3. 输入**同一主密码**
4. 笔记自动同步

## 3. 主题与个性化

### 3.1 切换主题

设置 → 主题 → 6 套主题任选：
- 薄荷晨光（默认）
- 雾霭蓝调
- 暮色森林
- 焦糖暖光
- 樱粉物语
- 极简白

### 3.2 切换明暗

外观模式：
- 跟随系统
- 始终亮色
- 始终暗色

### 3.3 字体与密度

- **字体**：系统默认 / 思源黑体 / 霞鹜文楷
- **密度**：舒适 / 标准 / 紧凑

## 4. 导入与导出

### 4.1 导入

支持 `.txt` / `.md` / `.docx`

设置 → 导入导出 → 选择文件 → 预览 → 确认

冲突时可选：**合并 / 覆盖 / 跳过**

### 4.2 导出

支持 **Markdown / HTML / PDF / JSON**

设置 → 导入导出 → 选择格式 → 筛选范围 → 下载 ZIP

**全量备份**推荐使用 JSON 格式。

## 5. 分享

### 5.1 创建分享

1. 打开笔记
2. 点击右上角 ⋯ → 分享
3. 可选：
   - 访问密码（4-32 位）
   - 有效期（1 天 / 7 天 / 30 天 / 永久）
   - 备注（仅自己可见）
4. 复制链接或扫码分享

### 5.2 管理分享

设置 → 分享管理

可查看：
- 链接状态
- 查看次数
- 过期时间

可操作：
- 复制链接
- 调整过期
- 吊销（立即失效）

## 6. 设备管理

设置 → 设备管理

可查看所有已登录设备，点击 **踢出** 立即清除该设备的会话。

## 7. 自动锁屏

默认空闲 **15 分钟**自动锁屏。可在设置中调整为 5/15/30/60 分钟或"永不"（不推荐）。

移动端切到后台时**立即**锁屏。

## 8. 数据管理

### 8.1 导出全部

设置 → 数据 → 全量导出 → 收到加密 ZIP

ZIP 含 `notes.json`、`tags.json`、`preferences.json`、`attachments/`。

ZIP 使用**导出密码**加密（与主密码不同），请妥善保管。

### 8.2 删除账户

设置 → 数据 → 删除账户

⚠️ 30 天后物理删除，期间可登录恢复。

## 9. 常见操作

### 9.1 找回主密码

1. 解锁页 → "忘记密码"
2. 输入 12 位恢复码
3. 设置新主密码

### 9.2 跨设备转移

方法 A：登录同一账户自动同步
方法 B：导出 → 在新设备导入

### 9.3 离线使用

- Web：依赖浏览器 IndexedDB，断网仍可读已缓存笔记
- 桌面：本地 SQLite，完全离线可用
- Android：本地 SQLite，完全离线可用
- 小程序：依赖网络

## 10. 故障排除

| 现象 | 排查 |
|------|------|
| 忘记主密码 | 用恢复码重置 |
| 同步卡顿 | 检查网络 / 重启应用 / 设置 → 数据 → 强制同步 |
| 主题未生效 | 重启应用 |
| 笔记丢失 | 检查回收站 / 设置 → 数据 → 查看最近活动 |
| 编辑器卡顿 | 拆分超大笔记（> 50k 字） |
