# 常见问题（FAQ）

> 适用版本：v1.0.0 及以上

## 基础

### DustNote 是免费的吗？

是。当前所有功能免费，无内购，无广告。

### 为什么不开发多用户版本？

定位就是**单用户私人笔记**。多用户会带来账号体系、团队管理、协同等复杂度，与"零门槛"理念冲突。

### 数据存在哪里？

默认存储在我们的云服务（中国大陆节点）。你也可以[自托管](./self-hosting.md)到自己服务器。

### 端到端加密是什么意思？

你的笔记在**离开设备前**已经加密，服务端只保存密文，看不见明文。这意味着：

- 我们**无法**读取你的笔记
- 主密码遗忘 + 丢失恢复码 = 永久无法找回（这是设计）
- 即便服务端被攻破，攻击者也只能得到密文

## 账户与密码

### 忘记主密码怎么办？

在解锁页点击"忘记密码"，输入首次设置时生成的 **12 位恢复码** 即可重置。

### 恢复码也丢了？

很遗憾，无法找回。请立即：

1. 重新创建一个新账户
2. 在导入导出页导入旧账户的导出 ZIP（如果之前导出过）

**再次强调**：首次设置时抄写恢复码非常重要。

### 主密码会被保存吗？

不会。主密码仅用于在你设备上派生加密密钥，**永远不会传输到服务端**。服务端只保存单向哈希（Argon2id）用于校验。

### 主密码要设置多长？

- **最小**：10 字符
- **推荐**：16 字符以上
- **理想**：20 字符以上的口令短语（如 `森林-夜晚-薄荷茶-2026`）

## 同步

### 多久能同步到其他设备？

**1 秒内**（在线设备）。我们使用 WebSocket 实时通知。

### 没网能用吗？

- Web：能，已加载的笔记可读；新笔记保存到本地
- 桌面 / Android：完全离线可用，下次联网自动同步
- 小程序：依赖网络

### 多设备同时编辑会冲突吗？

**会**，但有保护：

- 系统检测到冲突会提示"远程版本更新"
- 你可以选择"采用本地"或"采用远程"
- **不是** Google Docs 级别实时协同（那是 v2.0 评估）

## 主题

### 主题怎么切换？

设置 → 主题 → 选择 → 实时预览

### 能自己写主题吗？

v1.x 暂不支持。v2.0 评估开放主题 API。

### 暗色模式会跟随系统吗？

会。设置 → 主题 → 外观模式 → "跟随系统"。

## 导入导出

### 能从其他笔记应用迁过来吗？

- v1.0：手动从其他应用导出为 `.md` 或 `.txt`，再导入 DustNote
- v1.1+：计划支持 Evernote、Notion、Apple Notes 一键导入

### 导出的文件可以重新导入吗？

JSON 备份可恢复；其他格式（Markdown/HTML/PDF）为只读归档。

## 分享

### 分享链接能被搜索引擎收录吗？

不能。我们主动 `X-Robots-Tag: noindex` 所有分享页。

### 分享密码忘了怎么办？

进入 设置 → 分享管理 → 吊销旧链接 → 重新创建。

## 安全

### 截图会被检测到吗？

- 移动端：已启用 FLAG_SECURE，截图会变黑屏
- 桌面 / Web：暂不支持系统级防截屏

### 会被社工吗？

不会。DustNote **永远**不会通过邮件、短信、电话联系你索要密码或恢复码。遇此类情况均为诈骗。

## 性能

### 能存多少笔记？

理论上无限。SQLite 实际可承载**百万级**笔记无压力。

### 笔记很长会影响性能吗？

- 笔记 ≤ 50k 字符：正常
- 笔记 > 50k 字符：建议拆分
- 笔记 > 200k 字符：编辑器会提示"建议拆分"
