# 常见问题（FAQ）

> 适用版本：v2.0.0 及以上

## 基础

### DustNote 是免费的吗？

是。当前所有功能免费，无内购，无广告。

### 为什么不开发多用户版本？

定位就是**单用户私人笔记**。多用户会带来账号体系、团队管理、协同等复杂度，与"零门槛"理念冲突。

### 数据存在哪里？

取决于你选择的模式（v2.0.0 新增）：

- **单机模式**：数据仅存在你的本设备（IndexedDB / AsyncStorage / Taro.setStorage），**永不离开设备**
- **联机模式**：数据加密后同步到服务器（自托管或公共服务器），服务端只存密文

你也可以随时[自托管](./self-hosting.md)到自己服务器。详见 [单机模式说明](../.trae/documents/standalone-mode.md)。

### 端到端加密是什么意思？

你的笔记在**离开设备前**已经加密，服务端只保存密文，看不见明文。这意味着：

- 我们**无法**读取你的笔记
- 主密码遗忘 + 丢失恢复码 = 永久无法找回（这是设计）
- 即便服务端被攻破，攻击者也只能得到密文

## 账户与密码

### 忘记主密码怎么办？

在解锁页点击"忘记密码"，输入首次设置时生成的 **10 位恢复码** 即可重置。

### 恢复码也丢了？

很遗憾，无法找回。请立即：

1. 重新创建一个新账户
2. 在导入导出页导入旧账户的导出 ZIP（如果之前导出过）

**再次强调**：首次设置时抄写恢复码非常重要。

### 主密码会被保存吗？

不会。主密码仅用于在你设备上派生加密密钥，**永远不会传输到服务端**。服务端只保存单向哈希（Argon2id）用于校验。

### 主密码要设置多长？

- **最小**：10 字符
- **推荐**：16 字符以上
- **理想**：20 字符以上的口令短语（如 `森林-夜晚-薄荷茶-2026`）

## 同步

### 多久能同步到其他设备？

**1 秒内**（在线设备）。我们使用 WebSocket 实时通知。

### 没网能用吗？

- **单机模式（v2.0.0 新增）**：所有端默认离线工作，完全不需要网络
- **联机模式**：
  - Web：能，已加载的笔记可读；新笔记保存到本地
  - 桌面 / Android：完全离线可用，下次联网自动同步
  - 小程序：依赖网络

### 多设备同时编辑会冲突吗？

**会**，但有保护：

- 系统检测到冲突会提示"远程版本更新"
- 你可以选择"采用本地"或"采用远程"
- **不是** Google Docs 级别实时协同（那是 v2.0 评估）

## 主题

### 主题怎么切换？

设置 → 主题 → 选择 → 实时预览

### 能自己写主题吗？

v1.x 暂不支持。v2.0 评估开放主题 API。

### 暗色模式会跟随系统吗？

会。设置 → 主题 → 外观模式 → "跟随系统"。

## 导入导出

### 能从其他笔记应用迁过来吗？

- v1.0：手动从其他应用导出为 `.md` 或 `.txt`，再导入 DustNote
- v1.1+：计划支持 Evernote、Notion、Apple Notes 一键导入

### 导出的文件可以重新导入吗？

JSON 备份可恢复；其他格式（Markdown/HTML/PDF）为只读归档。

## 分享

### 分享链接能被搜索引擎收录吗？

不能。我们主动 `X-Robots-Tag: noindex` 所有分享页。

### 分享密码忘了怎么办？

进入 设置 → 分享管理 → 吊销旧链接 → 重新创建。

## 安全

### 截图会被检测到吗？

- 移动端：已启用 FLAG_SECURE，截图会变黑屏
- 桌面 / Web：暂不支持系统级防截屏

### 会被社工吗？

不会。DustNote **永远**不会通过邮件、短信、电话联系你索要密码或恢复码。遇此类情况均为诈骗。

## 性能

### 能存多少笔记？

理论上无限。SQLite 实际可承载**百万级**笔记无压力。

### 笔记很长会影响性能吗？

- 笔记 ≤ 50k 字符：正常
- 笔记 > 50k 字符：建议拆分
- 笔记 > 200k 字符：编辑器会提示"建议拆分"

## 双模式架构（v2.0.0 新增）

### 什么是单机/联机双模式？

DustNote v2.0.0 引入双模式架构，让客户端在**完全没有服务器**的情况下也能独立运行：

- **单机模式（standalone）**：所有数据存储在本地，主密码本地校验，零服务器依赖，开箱即用
- **联机模式（online）**：连接 DustNote 服务器，解锁跨设备同步、在线分享、设备管理等高级能力

首次启动会让你选择模式。详见 [单机模式说明](../.trae/documents/standalone-mode.md)。

### 单机模式和联机模式有什么区别？

| 能力           | 单机模式              | 联机模式        |
| -------------- | --------------------- | --------------- |
| 笔记 CRUD      | ✅                    | ✅              |
| 主题/字体/密度 | ✅                    | ✅              |
| 导入/导出      | ✅                    | ✅              |
| 文件分享       | ✅（txt/md/html/pdf） | ✅              |
| 跨设备同步     | ❌                    | ✅（WebSocket） |
| 在线分享链接   | ❌                    | ✅              |
| 设备管理       | ❌（UI 隐藏）         | ✅              |
| 服务端备份     | ❌（仅本地导出 ZIP）  | ✅              |
| 服务端依赖     | 无                    | 必需            |

### 选了单机模式后还能切换到联机模式吗？

可以。支持 standalone ↔ online 一键迁移，**数据不丢失**：

- 单机 → 联机：设置 → 模式切换 → 输入服务器地址 + 主密码 → 自动上传本地数据
- 联机 → 单机：设置 → 模式切换 → 输入新主密码 + 恢复码 → 从服务器拉取全量密文

迁移是**原子化**的，任一步骤失败自动回滚，不会丢数据。详见 [用户手册 §12](./user-guide.md)。

### 单机模式数据丢失了怎么办？

单机模式数据仅存在本设备，**设备丢失则数据不可恢复**。建议：

1. **定期导出 ZIP 备份**：设置 → 数据 → 导出备份（建议每周一次）
2. **备份到多个位置**：云盘 / U 盘 / 加密邮件
3. **卸载 App 前必备**：卸载会清除本地数据

如果之前导出过备份 ZIP，可以在新设备导入恢复。

### 单机模式被锁定了怎么办？

单机模式有客户端锁定保护（防止离线爆破）：

- 连续 **6 次**密码错误 → 锁定 **15 分钟**
- 锁定期间无法尝试解锁
- 锁定计数器持久化，**重启 App 不重置**
- 成功解锁后失败计数清零

解决方法：

1. 等待 15 分钟后重试
2. 或点击"忘记密码"用 **10 位恢复码** 重置（重置后 masterKey 保留，历史笔记继续可用）

### 单机模式的主密码也走服务器校验吗？

**不走**。单机模式的主密码校验完全在本地完成：

- Argon2id 派生密钥 → 本地比对哈希
- 不发送任何请求到服务器
- 不生成 JWT
- 主密码永远不离开设备

### 单机模式忘记主密码怎么办？

和联机模式一样，用 **10 位恢复码** 重置：

1. 解锁页 → "忘记密码"
2. 输入 12 位恢复码
3. 设置新主密码
4. 系统生成**新恢复码**（旧恢复码失效）

**关键设计**：recover 后 masterKey 保留，**历史笔记密文无需重加密**，所有笔记继续可用。

### 恢复码也丢了怎么办？

很遗憾，无法找回。单机模式下：

1. 之前的笔记永久无法解密
2. 只能重新创建新的单机账户
3. 如果之前导出过备份 ZIP，可以导入恢复（但需要记得导出密码）

**再次强调**：首次设置时抄写恢复码非常重要。

### 小程序单机模式有什么限制？

微信小程序单机模式受存储容量限制：

- 单 key 上限 **10MB**
- 仅推荐轻量试用
- 数据量大请迁移到联机模式或使用桌面/Web 端

### 单机模式如何更新 App？

桌面端（单机/联机相同）通过**应用内更新**升级：

- 启动时静默检查，或设置 → 检查更新
- 请求服务器 `/api/v1/update-manifest` 获取最新版本与 SHA-256
- 从自托管服务器 `/downloads/` 下载安装包，校验一致后启动安装向导

联机模式的服务器版本另见服务器 `/api/v1/health` 的 `version` 字段。详见 [更新策略](../.trae/documents/update-strategy.md)。
