## 为什么值得写下来

这两天有两次「改了但没生效」的教训：一次是我把 `insecure-randomness` 当已修报告，实际污点图
没变（0003 记录了正确的做法）；一次是拨测钉了三个不存在的 commit，两天里一次都没跑过，而它的
报警步骤就在同一个 job 里（0004/0005 记录了处置）。这类事不写下来，半年后一定再犯。
