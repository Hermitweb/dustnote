# 微信小程序隐私合规上线清单（LIFE-012）

> 关联改动：`miniprogram/src/app.config.ts` 的 `__usePrivacyCheck__: true` +
> `miniprogram/src/app.tsx` 的 `onNeedPrivacyAuthorization` 全局处理。

## 已完成的代码侧

- [x] `__usePrivacyCheck__: true`——开启后隐私接口在用户未授权时挂起而非直接失败
- [x] `onNeedPrivacyAuthorization` 全局注册：弹官方风格授权弹窗，「同意」走
      `resolve({ event: 'agree' })`，「拒绝」走 `disagree` 让原接口按标准失败
- [x] 曝光上报 `resolve({ event: 'exposureAuthorization' })`
- [x] 触发点核查：当前唯一隐私接口为「导入备份」的 `Taro.chooseMessageFile`
      （`pages/settings/index.tsx`），失败分支已提示用户

## 上线前必须在微信后台完成（无法由代码代替）

1. **配置《用户隐私保护指引》**：小程序管理后台 → 设置 → 服务内容声明 →
   用户隐私保护指引填写。
   - 需声明的收集类型：**文件（导入备份时由用户主动选择）**
   - 用途表述：用户主动选择本地备份文件以恢复笔记数据
   - 声明「不收集：位置/通讯录/相册/麦克风（语音输入由微信同声传译插件
     处理，不上传开发者服务器）」
2. **等待审核通过**：指引审核通过后才对外生效；未配置时
   `getPrivacySetting().needAuthorization` 恒为 `false`（不弹窗也不拦截）。
3. **提审时勾选同步**：勾选「已阅读并同意遵守小程序用户隐私保护指引」
   后再提交版本。
4. **真机验证**：用未授权过的微信号首次触发「导入备份」，确认弹窗出现、
   同意后文件选择继续、拒绝后给出友好提示（而非静默失败）。
