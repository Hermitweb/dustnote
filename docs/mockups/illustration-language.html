DustNote · 插画语言提案

三态（空 / 加载 / 错误）已经有统一版面 StatePlate，但图版里仍是一枚图标。 这份提案给出一套可执行的插画语言：一支笔、两色、一个母题、三种笔法分状态。 先请你确认规则与画幅尺寸，再落地到三端。

一 · 八条规则

  1. 线稿，不吃填充。与 lucide 图标同一支笔：fill:none、stroke-width:1.5、圆头圆角。插画和图标并排时不会像"贴了张别人的图"。
  2. 两色 + 一档透明。主体走 currentColor（于是自动跟随文字层级与 tone：info 灰、guide 强调、danger 红），accent 只点一处——那个"你现在能做的动作"。第三档是 currentColor 12–16% 的地平线。不引入任何新色相：暗色档下"彩色位图抢过正文"正是 §U-1 点名要消灭的病。
  3. 尘埃母题。3 颗直径 2–3.2px 的圆点沿一条看不见的对角线散开，越远越淡。这是品牌（尘）的签名，也是六个状态之间唯一的共同元素。
  4. 一条地平线。主体坐在一条 currentColor/14% 的短横线上。没有它，东西在飘。
  5. 三种笔法分状态，不靠颜色。空态用虚线轮廓（"这里本该有东西"）；错误用断裂的实线（不连续=出错）；加载用旋转弧（与 spinner 同一支笔）。灰度打印也分得清。
  6. 空得越正常，笔墨越少。plain（回收站/收藏为空）只有地平线 + 一粒尘 + 一圈虚线；first-use 最重。读者用余光就能排出优先级。
  7. 画幅只有两档，且必须扩。plate 88×64、card 120×88。这是本提案唯一会改变版面密度的地方：现在的图版是 44×44 / 56×56 的方框，插画塞进去就退化成一个图标，等于白做。见第二节。
  8. 插画永远 aria-hidden。语义仍由标题与提示文字承担；屏幕阅读器不该因为一张画多听一句话。尘埃漂移 24s 与极光同档，motion-flat / prefers-reduced-motion 下静止。
