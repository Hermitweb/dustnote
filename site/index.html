MIT 开源 · 端到端加密 · 一条命令自托管

笔记留在你设备上，
服务器只搬密文。

DustNote 把加密放在客户端：主密码派生主密钥，逐条 AES-256-GCM 加解密，服务端与任何中间人都只见到密文。不配服务器它照样是一部完整的本地笔记；填上地址，五端开始同步。

下载客户端 自托管部署 源码仓库

无遥测 无第三方字体与统计请求 数据可完整导出 服务状态公开

它到底做了什么

下面每一条都能在仓库里指到具体实现；没做完的（比如附件系统）留在路线图里，不写在这页。

端到端加密

主密码经 PBKDF2-SHA256 十万轮派生主密钥；每条笔记单独 AES-256-GCM，AAD 绑定 noteId 与 userId，把密文挪到另一条记录会直接认证失败。

单机 / 联机双模式

同一套数据两种形态：不填地址是纯本地；填了就增量同步。断网写进离线队列，回来按游标续传，冲突交给版本号。

编辑器与整理

TipTap 富文本、任务清单、代码块、图片粘贴、标签 / 文件夹 / 回收站 / 模板、全文检索与批量操作，中英双语。

可控的公开分享

分享链接可设密码、有效期与查看上限；解锁失败会锁定，公开访问独立限流，免得自托管实例被人当公开接口刷。

账号加固

TOTP 二步验证、恢复码、按设备会话列表与撤销；access token 短时效，refresh token 走 httpOnly + SameSite=strict。

五端同一内核

加密、同步、存储与状态机沉到 client-core，Web / 桌面 / Android / 小程序 / H5 共用一套语义，避免各端漂移。

两种模式，不是两个产品

切换的只是「数据放在哪」，加密边界始终在设备上。

模式 A · 单机

零配置，数据只在本地

主密码即账号：本地派生密钥并封装主密钥，密文落在设备存储里。没有服务器、没有账号系统，也就没有可被攻破的中心。

  • · 本地锁定与自动锁屏
  • · 回收站保留期与本地备份导出
  • · 无需注册、无需网络

模式 B · 联机自托管

你自己的服务器，只存密文

服务端保存密文、校验参数与同步游标；它验证你是谁，但读不到你写了什么。换服务器、换域名、从备份恢复，都在一条 compose 命令的量级。

  • · 增量同步 + 离线写队列 + WebSocket 推送
  • · 跨端冲突按 version 裁决并保留副本
  • · /api/v1/health 与 Prometheus 指标口

安全模型

完整推导、威胁模型与已知取舍写在文档里，包括我们没做到的部分；这里只放结论。

发现漏洞请走 SECURITY.md 里的通道，不要开公开 Issue。

  • 明文不出设备：加解密只在客户端完成，服务端只搬密文
  • 派生参数随账号记录：历史 Argon2id 账号与新 PBKDF2 账号并存可解锁
  • AAD 绑定 noteId 与 userId：密文挪用到别的记录会认证失败
  • 凭据不落地：access token 短时效，refresh 走 httpOnly + SameSite=strict
  • 首屏零第三方请求：不加载外部字体、统计或徽章图片

怎么保证它没在偷偷坏掉

一个只写「我们有 CI」的项目等于没写。下面这些是每次 push 都会跑、失败就会挡合并的东西。

类型与规范
tsc 全量类型检查、eslint 分包、prettier；一条 pnpm verify 跑完 CI 的全部门禁
测试
各包 vitest 单测 + Playwright e2e，含视觉基线与对比度断言
安全
CodeQL 每次 push、pnpm audit、nginx 安全头继承守卫、action 钉版守卫
发布
镜像一次构建多平台推送、Docker 上下文 COPY 守卫、CI 里跑 nginx -t
运行
服务器本机监控 + GitHub 侧外部拨测双视角，失败开 issue、恢复自动关闭
文档
docs:check 守死链与孤儿文档，api:check 守接口清单与真实路由一致

一条命令起自己的实例

镜像一次构建多平台推送；compose 里已经把端口收窄到非特权 8080， TLS 交给外层负载均衡或 Caddy。健康检查与指标口开箱可用。

完整步骤、反代与 HTTPS 配置见 自托管指南 与仓库根 DEPLOY.md。
